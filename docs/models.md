# Models

Authored figures live in `public/models/<name>/` and are loaded by `src/actors/model.js`.

## In use

**Low-poly Game-Ready Knight Character** by kenzo (https://sketchfab.com/drkekker), CC-BY 4.0: https://sketchfab.com/3d-models/low-poly-game-ready-knight-character-c487d9200fa24b999f5bc71eb0741967

- The licence requires this credit wherever the game is shared: "This work is based on "Low-poly Game-Ready Knight Character" by kenzo, licensed under CC-BY-4.0." The game has no credits screen yet; it needs one before a build with this model on by default is published.
- A trial, on the captain only, behind the pause menu's CAPTAIN button.
- The published copy has its normal and metallic/roughness textures removed (the toon shading does not use them); the untouched download is in `assets/models/`.

## Downloaded, not used

All CC-BY 4.0 (licence files beside each in `assets/models/`).

- **Skeleton Lord** by DJMaesen: rigged (89 bones), 8.7k triangles, one walk/idle animation. Usable the same way as the knight once its 2048 px textures are shrunk (30 MB as downloaded).
- **Mercenary** by Fghdd42 (55k triangles, fifteen 2048 px textures, 65 MB) and **Warrior** (92k triangles, 19 MB): neither has a skeleton, so they are statues until someone rigs them in Blender, and both are too heavy for a phone as they are.
